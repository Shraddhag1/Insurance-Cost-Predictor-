# Insurance Charges Predictor

A machine learning project that predicts medical insurance charges using demographic and lifestyle features. It trains regression models and saves a Gradient Boosting model and feature scaler for later use.

## Project files

- `insurance_predictor.py` — trains and evaluates Linear Regression, Random Forest, and Gradient Boosting regression models.
- `train_model.py` — trains a Gradient Boosting Regressor and saves the trained model and scaler.
- `update_region.py` — replaces the dataset's `region` values with Indian city names.
- `scaler.pkl` — saved `StandardScaler` generated by `train_model.py`.
- `insurance.csv` — input dataset required by the scripts (must be provided separately).

Running `train_model.py` successfully also creates `gradient_boost_model.pkl`.

## Requirements

- Python 3.9 or newer
- pandas
- NumPy
- scikit-learn
- joblib

Install the dependencies:

```bash
python -m pip install pandas numpy scikit-learn joblib
```

## Dataset

Place `insurance.csv` in the project directory before running the training scripts. It must contain a `charges` column, which is the prediction target. Categorical columns are converted to numeric indicator columns using one-hot encoding.

The training scripts use an 80/20 train-test split with `random_state=42`.

## Run model comparison

```bash
python insurance_predictor.py
```

This script trains and evaluates three regression models:

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

It prints these test-set metrics:

- **MAE** — Mean Absolute Error
- **RMSE** — Root Mean Squared Error
- **R²** — coefficient of determination
  
## run the app.py 
python -m streamlit run app.py

## Train and save the Gradient Boosting model

```bash
python train_model.py
```

This script trains a `GradientBoostingRegressor` with 100 estimators and saves:

- `gradient_boost_model.pkl` — trained model
- `scaler.pkl` — fitted `StandardScaler`

Keep the feature columns and their order consistent when using the saved model for predictions.

##run the  app.py
python -m streamlit run app.py

## Update the region column

```bash
python update_region.py
```

This script replaces the `region` values with a repeating sequence of `Mumbai`, `Delhi`, `Pune`, and `Bangalore`, then writes the changes back to the CSV file.

**Warning:** The script modifies `insurance.csv` in place. Make a backup first. Its current file path is specific to one computer, so update `file_path` to the location of your dataset before running it.

## Notes

- `insurance.csv` must be supplied locally; the scripts do not create it.
- The scripts use categorical encoding and scaling. Use the same preprocessing and feature order for future predictions.
- Rerun `train_model.py` if you change the dataset or training pipeline.
- Predictions are estimates based on the supplied data and are not insurance-provider quotes or financial advice.
